# Task

- We are building an sticky notes application

# Background

- I need a simple web application to place quick notes and information I use often. I used to use an extension called sticky notes but the extension is no longer allowed. I do not want to build a chrome extension. Instead I want to build something simple that I can host a github page and that will use local storage \+ local file save in the computer.

# Technical Requirements

- **App name:** cork board  
- **Technology stack:** HTML/CSS/Vanilla Javascript  
  - Syntactic html  
  - CSS Framework: Bulma CSS (CDN allowed)  
  - Dark mode manual support via toggle  
  - Use Bento Grid design for Mobile Support. No REACT  
    - You can use this as an example: https://github.com/ra559/aid/tree/main/components/bento-ui  
  - Icons: use iconify.design icons library or another equivalent open source icons library (CDN allowed)  
  - Use the images located in the directory inspiration/ to design the general layout  
  - Use the images located in the directory inspiration/ for the sticky notes layout  
- **Database:** use a local file and local storage only. No servers. Everything must be computed on the Client Side.   
- The application must be CRUD  
  - Create sticky notes  
  - Add/Remove/Update sticky notes  
  - Select and delete a single and all sticky notes

# Constraints

- No Javascript runtimes  
- Under no circumstances this application should use: nodejs, bun, React, Svelte, Vue, or any other Web Framework

# Output

- 3 Files:  
  - index.html  
  - styles.css  
  - app.js
